# TikTok Username Checker ☕︎

The most honest and easiest-to-use TikTok username checker. Checks the availability of TikTok usernames from patterns, word lists (up to 416,000 words) or your own .txt file. Pause and resume any time.

## Installation

Python is required. Install it from https://www.python.org/downloads/ and tick **Add python.exe to PATH**.

Then extract the ZIP, open the folder, type `cmd` into the address bar and press Enter:

```
py -m pip install -r requirements.txt
py tiktok_checker.py
```

Next time you only need the second command.

## Tool

<img width="985" height="547" alt="Image" src="https://github.com/user-attachments/assets/58d29673-4b01-46ae-bf91-92725abcf7a3" />

Type a number, press Enter. For a first test choose `9`, then letters `5-6`, words `200`, order `1`, threads `1`. Results are saved in a new `Results_<date>_<time>` folder (`valid.txt`, `taken.txt`, ...). Press `Ctrl+C` to pause, the next start asks if you want to resume.

## Pro Tip

Ask any AI to make you a .txt file with words you like to check, for example: `ChatGPT make me a .txt file with 10000 Spanish words used in social interaction`. Put the file in the program folder, choose `f` in the menu and type its name.

## Note

AVAILABLE means TikTok shows no public profile for the name. Banned or deleted accounts look the same, so please verify each name in the TikTok app (Edit profile > Username). TAKEN is reliable.
